Lipid gallery
=============

One page for every lipid in the conformer collection pestifer ships: what it is, how it is drawn,
and every conformer the grid packer can place, so a reader can see what a built bilayer is made
of. Entries are grouped by the CHARMM topology file that defines them.

What a page carries
-------------------

Four things, in the order a reader wants them:

1. **Identity** — CHARMM resname, the name from the topology, charge, atom count, and which
   topology file defines it. All read from the force field, none transcribed.
2. **Structure** — a 2D diagram in the conventional lipid orientation: headgroup at the top,
   tails hanging down, no explicit hydrogens. Embedded as SVG so it scales.
3. **Conformers** — every shipped conformer rendered at **one shared scale**, with the
   per-conformer geometry beside them; a lipid with a liquid-ordered ensemble shows both, at the
   same scale. The shared scale is the point: framing each image to its own molecule would hide
   exactly the differences in extension the ensemble exists to provide.
4. **Provenance** — the generation settings the entry records about itself, so a reader can
   reproduce or audit it.

How the pages are made
----------------------

``build_gallery.py`` writes every page and the tables above from the shipped collection::

    uv run --extra ligand-paramgen python docs/source/lipid_gallery/build_gallery.py

It needs VMD and ImageMagick for the contact sheets, and RDKit and Open Babel for the 2D drawings.
``--pages-only`` rewrites the text without rendering; ``--only POPC DOPC`` limits it to some
entries.

**Contact sheets.** Each conformer is rendered by ``lipidsnap.tcl`` straight at tile size, 188 ×
332 pixels, tiled five across, and saved as a 64-color palette PNG — about 37 KB a sheet, with no
visible loss. One scale serves every conformer of an entry, both ensembles included: the largest
at which the farthest heavy atom of any of them stays inside 90% of the tile, computed from the
coordinates. Short and long lipids therefore each fill their tiles, and within a page extension
can be compared directly.

Drawing the 2D structures
-------------------------

``lipid2d.py`` draws them: Open Babel perceives bond orders from a 3D conformer, and RDKit does
the depiction. The orientation is derived from the molecule, never set per species, so it holds
across the collection:

- **Stand it up** so the headgroup sits above the chain attachments. The headgroup reference is
  phosphorus if the lipid has any (every glycerophospholipid and sphingomyelin; a cardiolipin has
  two), otherwise the whole polar N/O region, which is what a ceramide's head is.
- **Swing each tail** rigidly about its last substituted carbon until it hangs downward, fanned
  slightly so two chains leaving nearby attachments do not draw on top of each other. A rigid
  rotation leaves every bond length and angle inside the chain untouched.

No stereochemistry is drawn: these are identity and shape references, and stereochemistry
perceived from one conformer would mark every chain CH₂ as a stereocenter. Sterols come out in
their own conventional pose, 3-OH up and the iso-octyl tail down. ``CHM1``, a twelve-atom ring
model compound with no acyl chain, is not drawn.
