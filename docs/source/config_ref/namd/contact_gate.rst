``contact_gate``
----------------

  * ``enabled``: True
  * ``min_distance``: 1.2


Default for the pre-flight steric check, applied to EVERY task that runs dynamics. `md` stages may override it per stage; tasks whose own schema has no contact_gate key -- membrane_equilibrate, density_equilibrate, ligate, domainswap -- are controlled only from here.  Without this there is no way to disable the check on those tasks at all, which 3.28.0 shipped: the gate ran on them and no configuration could stop it.
