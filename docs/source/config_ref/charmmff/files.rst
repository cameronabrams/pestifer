.. _config_ref charmmff files:

``files``
---------



CHARMM force-field files to load, by basename, in load order. A basename from the official CHARMM release is found wherever it lives in the release tree; a basename in one of your ``searchpath`` directories is found there. These are appended to pestifer's default set, so they load last and win any duplicate parameter; set ``replace_defaults`` to make this list the whole set instead.
