``searchpath``
--------------



Directories holding your own CHARMM-format files (.rtf, .top, .str, .prm). Every such file found is registered by basename and indexed by the RESI/PRES records it contains, so it can be named in ``files`` or resolved automatically by residue name. Entries may contain ``~/`` or ``$VAR``/``${VAR}``; both are expanded before the directory is probed.
