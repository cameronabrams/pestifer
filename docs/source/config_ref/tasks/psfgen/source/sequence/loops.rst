``loops``
=========

Parameters controlling model-built loops during psfgen

Single-valued attributes:

  * ``sac_res_name``: 3-letter code of residue appended to any sufficiently long model-built (default: GLY)

  * ``min_loop_length``: Minimum length of model-built loop that triggers the ligation algorithm (default: 4)

  * ``widen_unclosable``: Release resolved residues flanking an interior gap that cannot close against its deposited anchors (at most 3 per side, never a disulfide or linked residue), so the loop is rebuilt and closed through them; each released residue is reported.  Needs a later ligate task. (default: True)
