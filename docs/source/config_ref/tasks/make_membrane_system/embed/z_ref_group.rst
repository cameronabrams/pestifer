``z_ref_group``
===============

VMD atomselect string defining a center of mass at a specific z

Single-valued attributes:

  * ``z_value``: value of z at COM of this group relative to apparent bilayer midplane z-value (Å) (default 0) (default: 0.0)

  * ``text``: the atomselect text
