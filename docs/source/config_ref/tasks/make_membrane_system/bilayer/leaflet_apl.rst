``leaflet_apl``
===============

Per-leaflet area per lipid, in square Angstroms, supplied instead of the value calibrated from the relaxed symmetric patches. Intended for re-using an APL measured on a large bilayer that has actually converged, because a short calibration patch cannot currently be trusted to produce the APL of the mixture it models: measured on a PIP2 mix, 45.63 on the patch against 43.47 on a 700-lipid bilayer, and with example 17's own settings a patch that reported itself CONVERGED at 88,210 steps certified 50.53 against a truth near 43. The grid is sized from this number, so an error here propagates into every leaflet count. Supply upper, lower, or both; whichever is omitted stays calibrated. The patch calibration still runs and its convergence gate still applies -- an override cannot suppress them. pestifer cannot check the value you give it, so the supplied number, the calibrated one it displaces, and the percentage between them are all logged, and the source of each leaflet's APL is recorded per leaflet in the run record.

Single-valued attributes:

  * ``upper``: area per lipid of the upper leaflet, in square Angstroms

  * ``lower``: area per lipid of the lower leaflet, in square Angstroms
