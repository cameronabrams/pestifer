``membrane_equilibrate``
========================

self-terminating NPgT density+area equilibration stage for bilayer relaxation (replaces a fixed NPT/NPgT tail; convergence specs default from the top-level membrane_equilibrate task)

Single-valued attributes:

  * ``temperature``: Temperature (K) (default: 310)

  * ``pressure``: Pressure (bar) (default: 1)

  * ``two_stage``: If true (default), settle density at constant lateral area first, then relax the area tensionless (see the top-level membrane_equilibrate task); false runs the legacy single-stage tensionless NPgT. (default: True)

  * ``constant_ratio``: If true (default), the tensionless area stage locks Lx:Ly (useConstantRatio). Set false for a calibration patch (no protein, no preferred aspect) so the flexible cell relaxes x and y independently -- on a non-square box a locked skewed ratio over-condenses the area along the short axis instead of settling. (default: True)

  * ``max_steps``: hard ceiling on total NPgT steps for this relaxation stage (default: 500000)

  * ``area_drift_tol``: per-stage override of the lateral-area drift tolerance (fraction). The default (0.012) suits a final relaxation, but a calibration patch sizes the whole grid and must satisfy make_membrane_system's 0.5% reliability check, so tighten it (e.g. 0.005) on calibration stages. Inherits the top-level membrane_equilibrate default when unset. (default: 0.012)

  * ``area_min_steps``: per-stage override of the minimum steps before the lateral area may be declared converged (a floor preventing premature convergence on a slow, e.g. cholesterol-rich, area relaxation). Inherits the top-level default when unset. (default: 40000)

  * ``area_plateau_tol``: cumulative area-plateau gate (fraction); when > 0, also require the stage-2 area's quarter-over-quarter drift below this before converging -- the same metric make_membrane_system uses to judge a calibration patch's preferred APL reliable. Set e.g. 0.005 on calibration stages; 0 (default) disables it. (default: 0.0)
