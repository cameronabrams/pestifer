``composition``
===============

Alternate way of expressing bilayer composition; supercedes memgen-format 'lipids', 'mole_fractions', and 'lipid_conformers'

Single-valued attributes:

  * ``upper_leaflet``: List of dicts with keys 'name', 'frac', and 'conf' for each lipid species

  * ``lower_leaflet``: List of dicts with keys 'name', 'frac', and 'conf' for each lipid species

  * ``upper_leaflet_phase``: Target physical phase of the upper leaflet: 'Ld' (fluid, disordered) or 'Lo' (liquid-ordered, e.g. a cholesterol-rich raft). Selects the conformer ensemble the grid packer uses for that leaflet -- Ld draws the fluid ensemble, Lo an extended/ordered one generated by tuning the MC trans bias to a higher chain order parameter. Default 'Ld' reproduces prior behavior. (default: Ld)

  * ``lower_leaflet_phase``: Target physical phase of the lower leaflet ('Ld' or 'Lo'); see upper_leaflet_phase. (default: Ld)
