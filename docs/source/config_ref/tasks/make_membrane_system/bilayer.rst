``bilayer``
===========

Parameters controlling bilayer generation

Single-valued attributes:

  * ``lipids``: declaration of lipids in each leaflet in memgen format LIP1[:LIP2][//LIP3] where ":" is an intra-leaflet separator and "//" is an inter-leaflet separator (default: POPC)

  * ``lipid_conformers``: declaration of which conformer index to pin for each lipid in memgen format C1:C2//C3; must be congruent with the lipids attribute. Empty (the default) leaves conformers unpinned, so the grid packer draws a conformer per lipid across the whole ensemble; an explicit integer pins that single conformer for the species. (default: )

  * ``mole_fractions``: declaration of mole fractions of each lipid in each leaflet in memgen format R1:R2//R3; must be congruent with the lipids attribute (default: 1.0)

  * ``half_mid_zgap``: extra gap between hydrophobic tails in bilayer during packing, Angstroms (default: 1.0)

  * ``solvents``: string in memgen format SOL1:SOL2:... (default: TIP3)

  * ``solvent_mole_fractions``: string in memgen format x_1:x_2:... (default: 1.0)

  * ``solvent_to_lipid_ratio``: ratio of solvent molecules to lipids in each leaflet; must be specified if solvents are present (default: 32.0)

  * ``SAPL``: estimate of surface area per lipid (Å²) for building initial patches (default: 75.0)

  * ``dims``: box dimensions in x, y, and z in Å; must be specified for a bilayer-only system

  * ``npatch``: box dimensions in number of patches in x and y

  * ``solution_gcc``: solution density in g/cc (default: 1.0)

  * ``cation``: name of salt cation (default: POT)

  * ``anion``: name of salt anion (default: CLA)

  * ``salt_con``: salt concentration in M

  * ``packer``: How to place the lipids. 'grid' (the only supported packer) places lipids on a per-leaflet orthohexagonal 2D lattice (oriented, tails toward the midplane), relying on the relaxation MD to resolve the initial overlaps. The packer writes a lipid-only system; the extra-membrane water chambers are then filled at true liquid density by a VMD solvate/autoionize step after the lipid psfgen, not by a lattice. (The former 'packmol' packer has been removed.) (default: grid)

  * ``quilt_grid_slack``: Linear factor by which the protein-embedding quilt is gridded looser than its calibrated stress-free box area, giving the lipid placement a small clearance before the tensionless relaxation condenses it to the preferred per-leaflet APL. 1.0 grids exactly at the stress-free area; the default 1.05 (~5% extra area) is a token placement margin. The old 1.15 (~32% extra area) was needed only for the square lattice's tight contacts and left the quilt badly under-dense. (default: 1.05)

  * ``seed``: RNG seed (optional)
