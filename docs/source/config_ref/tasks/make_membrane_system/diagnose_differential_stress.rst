``diagnose_differential_stress``
================================

After assembling a stress-free asymmetric membrane, run a short tensionless pressure-profile pass and report the residual per-leaflet surface tensions, their difference (the differential stress), and the leaflet-count adjustment that would null it. Diagnostic only: the membrane is neither rebuilt nor advanced -- the state that goes on to be embedded is the convergence-gated one this pass measured, not the pass's own final frame. Requires a CPU (non-CUDA) NAMD build. The profile is first checked against NAMD's own PRESSURE; if its slab average is more than 2000 bar away, as happens with a NAMD build that writes wrong pressure profiles, nothing is reported from it.

Single-valued attributes:

  * ``enabled``: turn on the differential-stress diagnostic for asymmetric builds (default: False)

  * ``nsteps``: number of MD steps in the tensionless pressure-profile pass (default: 100000)

  * ``slabs``: number of z-slabs for the pressure profile (pressureProfileSlabs) (default: 40)

  * ``freq``: steps between pressure-profile samples (pressureProfileFreq) (default: 500)

  * ``area_modulus``: assumed per-leaflet area-compressibility modulus K_A (mN/m), used to convert the residual differential stress into a suggested leaflet-count change (default: 250.0)

  * ``temperature``: Temperature (K) for the pressure-profile pass. Leave unset to inherit the temperature the quilt's own relaxation protocol ended at, which is almost always what you want: the pass must sample at the state point the membrane was equilibrated at. A mismatch does not fully cancel in the reported difference of leaflet tensions, because the two leaflets of an asymmetric bilayer do not share a thermal expansivity.
