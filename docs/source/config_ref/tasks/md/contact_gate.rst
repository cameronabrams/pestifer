``contact_gate``
================

Pre-flight steric check.  Before DYNAMICS starts (never before a minimize, which is the remedy for an overlap), the coordinates NAMD is about to read are scanned for a pair of heavy atoms that are not 1-2 or 1-3 bonded and are closer than min_distance; if one is found the build stops and names the two residues.  A steric overlap is fatal to the run regardless -- NAMD reports it as "Constraint failure in RATTLE algorithm for atom N" once the run has started -- so this only decides whether the failure is diagnosable.  On a healthy embedded membrane the closest such pair was 2.525 A, on solvated BPTI 2.478, and on BPTI straight out of psfgen 1.819 -- so the default of 1.2 sits 0.6 A below the closest legitimate contact measured, rather than at the edge of it.

Single-valued attributes:

  * ``enabled``: whether to run the pre-flight steric check before a dynamics stage (default: True)

  * ``min_distance``: heavy-atom separation in Angstroms below which a non-bonded pair is treated as a steric overlap rather than a close contact (default: 1.2)
