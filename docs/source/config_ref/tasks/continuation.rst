``continuation``
================

Continue from specified pdb, psf, and (optionally) xsc, vel, and coor files

Single-valued attributes:

  * ``psf``: name of psf file (w/optional .psf extension)

  * ``pdb``: name of pdb file (w/optional .pdb extension)

  * ``xsc``: name of xsc file (w/optional .xsc extension)

  * ``coor``: name of coor file (w/optional .coor extension)

  * ``vel``: name of vel file (w/optional .vel extension)

  * ``verify_parameters``: If true, parse the incoming PSF once to (a) classify its residues and report a segid inventory plus any unknown residue names, and (b) verify force-field consistency -- every atom type and every bond/angle/dihedral/improper type-tuple in the PSF must resolve against the build's CHARMM release, hard-erroring up front (naming the residue and term) on a miss rather than failing cryptically deep in a later NAMD run. Intended for bringing in a foreign PSF (e.g. from CHARMM-GUI); pestifer's own internal continuations set this false to keep the zero-parse fast path. (default: True)
