``panels``
----------



Stacked panels sharing one time axis, given as a list of traces (or lists of traces, to overlay several in one panel). Density, area and temperature read together tell a story that three separate figures do not, because the eye cannot align three x axes; this is also the shape the equilibration tasks draw by hand.
