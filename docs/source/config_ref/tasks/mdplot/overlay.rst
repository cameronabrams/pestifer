``overlay``
-----------



Other runs to draw alongside this one for comparison, each a dict with a `label` and a list of `logs`. One figure per plotted quantity with one curve per run. Comparing builds that differ in a single respect -- the same protein in three solvents, or a parameter changed -- is otherwise a matter of holding two figures side by side and guessing whether the axes match.
